# 📊 Sales Dashboard using Tableau

This project presents an interactive and visually appealing **Sales Dashboard** built using **Tableau Public**.  
It analyzes product performance, country-level sales, deal sizes, and monthly sales trends using real-world sample sales data.

## 📌 Project Objectives

- Build a professional interactive **Sales Dashboard** in Tableau  
- Analyze key metrics such as Sales, Quantity, and Avg Price  
- Provide insights into product performance, country performance, and time trends  
- Demonstrate dashboard interactivity with filters  
- Present insights through a PPT summary  

---

## 📊 Dashboard Overview

The dashboard includes:

### ✔️ KPI Cards
- Total Sales  
- Total Quantity  
- Average Price  

### ✔️ Visualizations
- **Sales by ProductLine** (Bar chart)
- **Sales by Country** (Filled map)
- **Sales by Dealsize** (Treemap)
- **Monthly Sales Trend** (Line chart)
- **Filters**: Country, ProductLine, Year_ID

---

## ⭐ Key Insights

- Classic Cars generate the highest sales  
- USA leads globally in revenue  
- Medium deal size contributes most to sales  
- November is the peak sales month  
- Some products and regions show improvement opportunities  

(Detailed insights available in `docs/insights.txt`)
